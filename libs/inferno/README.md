# Inferno Library

Inferno is an inference engine library made to create expert systems in Soluna

This is a **WIP** it's not final and is subject to change. I think it's still a bit hard to use in my opinion but there is a base.

## Functions

- inferno-fact: add a fact to the base
- inferno-facts: add a list of fact to the base
- inferno-rule: add a rule to the base
- inferno-ask: query the engine to get a solution
- inferno-reset: reset the base

maybe more, I don't remember
